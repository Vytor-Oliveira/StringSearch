Arquitetura · Padrão Strategy + Observabilidade

Padrão Strategy (GoF)

Define uma família de algoritmos, encapsula cada um e os torna intercambiáveis.

  • → SearchStrategy — Interface base
  • → NaiveSearch — ConcreteStrategy
  • → RabinKarpSearch — ConcreteStrategy
  • → KMPSearch — ConcreteStrategy
  • → BoyerMooreSearch — ConcreteStrategy
  • → SearchContext — Context
  • → StrategyFactory — Factory

SearchResult

  • → algorithmName · timeMs
  • → totalComparisons · occurrences
  • → positions · theoreticalComplexity
  • → traceId · spanId

OpenTelemetry (observability/otel.js)

  • → OtelSpan — representa um span
  • → OtelTracer — gerencia traces/spans
  • → OtelMetrics — contadores, histogramas
  • → OtelLogger — logs por severidade
  • → OtelExporter — exportação OTLP/JSON

Estrutura de Arquivos

  • backend/ — lógica de servidor (futuro)
  • css/styles.css
  • js/algorithms.js — Strategy + SearchResult
  • js/app.js — AppController + Dashboard
  • observability/otel.js — OTel SDK
  • docker-compose.yml — Jaeger + Prometheus
  • index.html
